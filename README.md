# チャンスアラーム

5分・15分刻みで、チャンスタイミングの1分前にアラームを鳴らすWebアプリです。

---

## ファイル一覧

| ファイル | 用途 |
|---|---|
| `chance-alarm.html` | スマホ用（iPhone Safari → ホーム画面に追加） |
| `chance-alarm-pc.html` | PC用（Mac/Windows Chrome・Safari） |

---

## PC版の使い方

### Mac - Chrome（推奨）

バックグラウンド通知に対応しています。

1. `chance-alarm-pc.html` のURLをChromeで開く
2. **「通知を許可する」** ボタンをクリック
3. Chromeの通知許可ダイアログで **「許可」** をクリック
4. モード（5分 or 15分）をONにする
5. タブを開いたままにすれば、別の作業中でも通知が届く

> **通知が許可できない場合**
> アドレスバー左の 🔒 アイコン → 「通知」→「許可」に変更 → ページ再読み込み

---

### Mac - Safari

Safariはバックグラウンド通知に対応していません。  
**タブを前面に表示したまま**使う場合のみ動作します。

1. `chance-alarm-pc.html` のURLをSafariで開く
2. モード（5分 or 15分）をONにする
3. タブを表示したままにする（バックグラウンドでは通知されない）

> バックグラウンド通知が必要な場合はChromeをご利用ください。

---

### Windows - Chrome

Macと同じ手順で動作します。

1. `chance-alarm-pc.html` のURLをChromeで開く
2. **「通知を許可する」** ボタンをクリック
3. Chromeの通知許可ダイアログで **「許可」** をクリック
4. モード（5分 or 15分）をONにする
5. タブを開いたままにすれば、別の作業中でも通知が届く

> **通知がブロックされている場合**  
> Chrome右上の「︙」→ 設定 → プライバシーとセキュリティ → サイトの設定 → 通知 → 該当URLを「許可」に変更

---

## スマホ版の使い方（iPhone）

1. `chance-alarm.html` のURLをSafariで開く
2. 画面下部の 共有ボタン（□↑）をタップ
3. **「ホーム画面に追加」** を選択 → 「追加」
4. ホーム画面のアイコンから起動する

> iOSの仕様によりバックグラウンド通知には対応していません。  
> 画面を表示したまま使用してください。

---

## アラームのタイミング

### 5分モード
毎時 `:04` `:09` `:14` `:19` `:24` `:29` `:34` `:39` `:44` `:49` `:54` `:59` に鳴ります。  
（5分・15分・30分・45分・0分の、それぞれ1分前）

- 通常の5分刻み → 高音の短いビープ音
- 15分刻み（:14 :29 :44 :59）→ 和音の3連ビープ音（15分モードと同じ音）

### 15分モード
毎時 `:14` `:29` `:44` `:59` に鳴ります。  
（15分・30分・45分・0分の、それぞれ1分前）

5分モードと15分モードは同時にONにできません。

---

## タブタイトルの見方（PC版）

タブを見るだけで状況が確認できます。

```
🔵 次:14 あと2:33 | 10:32:27   ← 5分モード稼働中
🟠 次:29 あと4:12 | 10:25:48   ← 15分モード稼働中
⏸ 10:32:27 | チャンスアラーム  ← オフ
```
